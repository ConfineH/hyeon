# Prompts para Google Stitch

Pégalos en [Stitch](https://stitch.withgoogle.com). Una corrida por propuesta. Sube `public/jose-antonio-hyeon.jpg` como referencia de retrato si Stitch lo permite.

No pidas que reescriba el copy: el texto canónico está en el sitio. Stitch debe proponer **layout, ritmo y atmósfera**.

---

## Prompt A — plaza nocturna (dirección actual, no clonar Inter/cream)

Anatomy: One-page personal website, mobile-first, long vertical scroll, editorial letter not a portfolio. Sticky top bar with the person’s name on the left and a single in-page link “Escribir” on the right. Hero: large square photographic print of a man in a cap and glasses (not a circular avatar), then his name in a distinctive display face, then one long sentence as the thesis. Below, a full-bleed warm khaki slab for the live product (Migajas). Then a night-ground section of two editorial rows (not cards) for other products. Then a pale stone field for a discontinued learning case with a three-part summary row. Then a short “how I work” block. Close with a large text email, not a second button.

Vibe: Night plaza after rain. Warm black ground, one lit face, khaki as the only large color field. Quiet, intimate, slightly cinematic. Almost no radius (2px). Offset shadows, never neon glow. Spanish typography that feels like a letter. Not a SaaS landing, not a studio, not glassmorphism, not bento grid, not cream-and-terracotta startup template.

Content: Jose Antonio Hyeon, product manager in Spanish. Headline idea: he builds products with a clear intention — to improve someone’s life. Live product: Migajas, a course that helps people with diabetes count carbs from everyday food. One primary button: “Entrar en Migajas”. Other work as narrative rows: Meant To (relationships), Fachada (housing). Learning case: Sí Quiero, a real problem that was not a sustainable business — no live CTA. Footer contact: joseahyeon@gmail.com as a text link.

Constraints: Single route. One primary CTA. Email is not a twin button. No LinkedIn/GitHub icons. No logo lockup like “Hyeon Studio”. No case-study cards, no stack dump, no CV timeline, no metric badges. Desktop from md: photo left, text right, top-aligned. High contrast, accessible type sizes.

## Prompt B — revista impresa

Anatomy: Same one-page content order as Prompt A. Layout like a Spanish cultural magazine: oversized name as a masthead, photo as a full-bleed crop on mobile and a printed plate on desktop, pull-quote for the thesis, then a khaki “Ahora” insert like a bound-in card. Product rows as a contents list with page numbers as decorative labels. Learning case as a boxed footnote spread. Email as a colophon.

Vibe: Print editorial, ink, paper grain implied not literal, generous margins, crop marks as a tiny motif if at all. Warm, literate, slightly austere.

Content: Same as Prompt A.

Constraints: Same as Prompt A. Do not add a blog index or extra pages.

## Prompt C — mesa de trabajo

Anatomy: Same sections. The page feels like a desk at night: photo as a physical object overlapping the khaki band, handwritten-feeling kicker “Ahora”, products as stacked sheets, Sí Quiero as a sheet turned over (stone instead of night).

Vibe: Tactile, analog, imperfect edges, warm lamp light. Still digital-clean, not collage clutter.

Content: Same as Prompt A.

Constraints: Same as Prompt A. No skeuomorphic wood textures that fight readability.

## Prompt D — contraste alto, más quieto

Anatomy: Same order. More whitespace, fewer shadows, type does the hierarchy. Khaki band is a thin ribbon instead of a slab. Photo smaller. Learning case is a simple three-column line.

Vibe: Quiet museum wall. Almost monastic. Warm black, stone type, khaki used sparingly.

Content: Same as Prompt A.

Constraints: Same as Prompt A. Must still feel like a person, not a luxury brand.
